## 7. Asset register

For every approved reference asset, record:
- Asset ID and filename
- Character / location / prop represented
- Canon status and approval date
- Age / costume / scene applicability
- Source prompt and model/provider
- Known deviations or limitations
- Related shots and episodes

Do not use a generated image as a definitive reference merely because it looks appealing. The creator must approve the design first.

## 8. Episode handoff checklist

Before starting the next episode:
- Update the canon decision log.
- Record unresolved mysteries and what has been revealed to the audience.
- Record each character's knowledge, beliefs, relationships, injuries, and current location.
- Record power progression and costs.
- Record changes to props, costumes, and reference assets.
- Record the timeline and travel implications.
- Identify any deliberate continuity misdirection (rumour, false belief, unreliable account).
- Confirm the cliffhanger's exact state so the next episode begins consistently.
